## Telegram 与 TG 的关系

Telegram 是这款即时通讯软件的名字，中文用户常叫它「纸飞机」「电报」「飞机」，**TG** 则是 Telegram 的缩写，三个说法指的是同一个东西。搜索里常见的「tg账号」「telegram账号」「纸飞机账号」，本质上也是同一类账号。

需要区分的是 **推特账号**。推特（Twitter，现名 X）的图标是一只蓝色小鸟，常被叫作「小蓝鸟」，和 Telegram 的纸飞机完全是两家公司、两套账号体系。推特账号不能登录 Telegram，Telegram 账号也不能用来发推文。两者只在「都需要手机号或邮箱注册」这一点上相似，风控规则、封禁逻辑、账号价值都不相通。

## Telegram 账号是什么

Telegram 账号的核心是一个**手机号**。注册时用哪个国家的号码，账号的初始归属地就是哪里；注册完成后可以设置用户名（username），别人通过 `@username` 就能找到你，不必知道你的手机号。

几个容易混淆的点：

- 账号没有等级，也没有「养成」机制，所谓新号、老号指的是**注册时长**，不是等级高低
- 账号信息保存在云端，换手机登录后聊天记录、群组、收藏都会同步回来
- 同一个账号可以同时登录多台设备，包括手机、桌面端和网页版
- 两步验证密码是独立于短信验证码的第二道锁，设置后换设备登录必须输入
- 手机号可以后期更换，但换号后原号码会与账号解绑，操作前要确认新号码能正常收码

## 注册流程

不管用自己手机号还是接码号，注册的核心步骤只有四步：

1. **下载官方客户端**：手机端走 App Store 或 Google Play，桌面端从 telegram.org 下载，不要用来源不明的修改版
2. **准备可用手机号**：自有号码最稳；没有可用号码时才会考虑接码号，选择时要看号段是否被大量注册过
3. **接收并输入验证码**：验证码是 5 位数字，可能以短信、来电或已登录设备内消息的形式送达
4. **完成初始设置**：设置中文界面、开启两步验证、绑定恢复邮箱、调整隐私选项

三种注册方式的差别可以用一张表看清楚：

| 方式 | 大致成本 | 成功率 | 适合场景 | 主要风险 |
|------|---------|--------|---------|---------|
| 自有手机号 | 0 元 | 高 | 个人长期使用 | 号码暴露给通讯录，可在隐私设置里限制 |
| 接码号 | 单次几元 | 中等 | 需要多个账号、临时使用 | 号码被回收后可能失去账号，售后依赖服务商 |
| 直接买现成号 | 十几元起 | 高 | 不想自己养号、需要账号年龄 | 来源和绑定信息不透明，可能被原持有人找回 |

自己注册的成本最低，也最可控。接码号适合有明确数量需求的场景，但要做好「号码不是自己的」的心理准备。买现成号则要先弄清账号年龄、绑定信息和售后范围，这部分在后面的选购章节展开。

## 下载与版本选择

下载环节最容易出问题的地方不是「找不到安装包」，而是**装到了改过的版本**。第三方修改版可能内置后门、窃取登录会话，或者夹带推广模块，账号被盗往往从这一步开始。

判断渠道是否可靠，可以按这个顺序：

- 手机端优先应用商店的官方条目，开发者信息应与 Telegram 官方一致
- 桌面端从 telegram.org 的下载页进入，或使用官方在 GitHub 维护的桌面客户端仓库
- 安卓的 APK 只从官网或官方 GitHub 发布页获取，不用网盘转存包
- iOS 需要对应地区的 Apple ID 才能在 App Store 搜到，换区下载属于常见做法，但不要把 Apple ID 交给他人代操作

版本更新不必追新，但安全更新要及时。客户端长期不更新，可能无法接收新格式的消息，也会错过官方修补的漏洞。

## 登录与验证码

登录和注册用的是同一个验证码通道，所以「收不到验证码」既可能发生在注册，也可能发生在换设备登录时。常见原因按出现频率排列：

- 运营商拦截国际短信，尤其是 +86 号码，需要联系运营商确认是否开通
- 号段被大量注册过，平台不再向该号码发送短信
- 短时间内反复请求，触发频率限制，通常等 10 到 15 分钟再试
- 国家代码填错，中国大陆是 +86，香港 +852，台湾 +886
- 手机装了拦截类应用，短信被归入垃圾箱

如果账号还登录在旧设备上，验证码会优先以应用内消息推送，这时候不用等短信，直接在旧设备里看即可。已经开启两步验证的账号，输入验证码后还要再输入密码；密码忘了只能通过恢复邮箱重置，所以**恢复邮箱一定要填自己常用的**，并且确认能收到邮件。

登录后建议顺手检查「设置 → 设备」里的活跃会话，把不认识的和已经闲置的设备退出。公共电脑上登录过的话，这一步尤其重要。

## 日常使用

Telegram 的功能不算复杂，新手最容易卡在语言和隐私两项设置上。

界面语言可以在「设置 → 语言」里切换为简体中文，也可以安装中文语言包。隐私设置里值得逐项确认的有：手机号对谁可见、是否允许通过手机号找到我、上次上线时间是否公开、是否允许陌生人拉群。默认设置偏开放，改成「仅联系人」通常更符合中文用户的使用习惯。

群组和频道是 Telegram 的主要内容形态。群组是多人对话，频道是单向广播。加入陌生群组前先看群规和成员构成，涉及投资、兼职、空投的群组风险较高。文件传输方面，普通账号单文件上限是 2GB，开通会员后放宽到 4GB，传输的文件会保存在云端，过期时间取决于文件类型。

网络不稳定时会出现消息发送失败、图片加载不出来，这通常是本地网络到 Telegram 服务器的链路问题，和账号本身无关。判断方法很简单：换个网络环境再试，如果恢复正常，就不用怀疑账号被封。

## 账号安全

账号安全可以拆成「防丢」和「防骗」两件事。

防丢的关键动作只有三个：

- **开启两步验证**：设置一个独立的密码，不要和邮箱、其他网站复用
- **绑定恢复邮箱**：密码忘记时这是唯一的自助找回入口，邮箱本身也要开两步验证
- **定期检查活跃会话**：发现陌生设备立即退出，并修改两步验证密码

防骗更多是习惯问题。任何以「账号异常需要验证」「空投领取」「客服协助解封」为由索要验证码、两步验证密码、登录二维码的，都是骗局。Telegram 官方不会通过私聊索要这些信息，也不会要求你扫码登录陌生网站。陌生人发来的文件和 APK 不要点开，这类文件常被用来窃取会话。

账号被冻结时，可以在登录界面按提示提交申诉，说明注册号码、使用场景和封禁时间。申诉结果由平台判定，周期通常是几天，重复提交不会加快进度。与其反复申诉，不如把精力放在新账号的规范使用上。

新号和老号的差别只有一条：**注册时长**。价格差好几倍，差的就是这条时间线，以及时间线带来的风控宽容度。

|------|----------------|------------------|
| 参考价格 | 几元到十几元 | 十元到十六元左右 |
| 注册时长 | 刚注册到几个月 | 1 年以上，常见 1 到 10 年 |

## 账号购买注意事项

账号交易本身处在灰色地带，本站不提供账号，也不推荐具体商家，只整理判断思路。真正需要盯住的是四件事：

**来源是否说得清。** 卖家能不能说明号码归属国家、注册时间、是否接过码、有没有被限制记录。说得越具体，后续扯皮的概率越低。

**绑定信息是否可控。** 拿到账号后能不能改密码、能不能绑定自己的邮箱、原来的恢复邮箱是否已解绑。如果这些都不能动，账号实际上还在别人手里。

**售后范围是否明确。** 「首登质保」是常见承诺，指的是第一次登录成功，不等于长期可用。质保多久、什么情况算售后、封号是否负责，都要提前问清。

**承诺是否离谱。** 凡是打着「100% 安全」「永久不封」「绝对稳定」旗号的，直接跳过。平台风控随时变化，没有任何卖家能给出这种保证。

另外几类服务不要碰：盗号、撞库、拦截他人验证码、窃取 Cookie 或 Token、绕过平台验证和风控、批量规避限制。这些不只是违反平台规则，很多已经涉及违法，买家和卖家都有风险。本站不提供、也不介绍这类内容。

## 推特账号与 TG 账号的区别

推特账号（X 账号，俗称小蓝鸟）和 Telegram 账号经常被放在一起搜索，但两者的用途和风险完全不同。

推特账号以内容发布和社交为主，注册可以用手机号或邮箱，风控重点在设备、IP 和行为模式；账号价值更多体现在注册时长、粉丝和内容历史。Telegram 账号以通讯和群组为主，手机号是核心标识，风控重点在号码来源和登录环境。两者的账号不能互通，也不存在「一个号登录两个平台」的做法。

需要提醒的是，推特账号的交易风险普遍高于 Telegram：绑定邮箱难改、原持有人可以通过申诉找回、批量注册的账号容易被成批封禁。本站目前的内容集中在 Telegram 和 TG 账号，推特账号的注册、养号与选购资料还在整理，暂时没有独立栏目，也不会以「推特账号」的名义提供账号交易。等资料成形后会按同样的标准补充到站内，不会先放空页面占位。

## 常见问题

**Telegram 和 TG 是同一个东西吗？**
是。TG 是 Telegram 的缩写，纸飞机、电报、飞机都是中文用户对它的俗称。

**注册 Telegram 要花钱吗？**
注册本身免费，成本来自手机号。自有号码零成本，接码号单次几元，直接买现成号十几元起。

**收不到验证码怎么办？**
先确认国家代码没填错，再检查短信拦截和运营商是否屏蔽国际短信。仍收不到就等 10 到 15 分钟，避免连续请求。账号还在旧设备上登录的话，验证码会推到应用内。

**提示手机号已被注册怎么办？**
说明这个号码已经注册过 Telegram。可以尝试用该号码登录，走「忘记密码」重置；无法重置就只能换号。

**新号刚注册就被限制？**
新号触发风控很常见。首登后静置 12 到 24 小时，别马上加群或群发，先开启两步验证、绑定邮箱，并保持设备和网络稳定。

**两步验证密码忘了怎么办？**
通过注册时绑定的恢复邮箱重置。没绑邮箱的账号基本无法自助找回，这也是为什么注册后第一件事就该绑邮箱。

**账号被冻结怎么申诉？**
在登录界面按提示提交申诉，写清注册号码、封禁时间和用途说明。结果由平台判定，通常需要几天，重复提交没有帮助。

**买现成账号安全吗？**
没有绝对安全的交易。重点看来源是否可追溯、能否改密码和绑定邮箱、售后范围是否写清楚，以及卖家有没有给出不切实际的承诺。

**推特账号和 Telegram 账号通用吗？**
不通用。两家公司、两套体系，账号、验证码、封禁规则都相互独立。
